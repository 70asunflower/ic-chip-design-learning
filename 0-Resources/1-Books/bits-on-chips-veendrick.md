# Bits on Chips（芯片上的比特）· 第 3 版

> Harry Veendrick · Springer · 2026-07-02（第 3 版）· 英文原版

## 内容简介

集成电路（微电子）通识类导论读物，由前 NXP 资深工程师 Harry Veendrick 撰写。完整讲解芯片从设计、工艺制造到系统应用的全链条知识，覆盖先进制程、2nm 节点与芯片产业生态。公式推导极少，侧重概念与行业全景，兼顾零基础科普与工程宏观概述。

## 内容覆盖

- **全链条视角**：芯片设计 → 工艺制造 → 封装测试 → 系统应用
- **先进制程**：覆盖至 2nm 节点，并包含 More than Moore（微/纳机电系统、微化学系统、传感器与执行器）
- **产业生态**：芯片产业链、设计 / 制造 / EDA 分工全景
- **双受众结构**：第一部分面向几乎无技术背景的读者（用「芯片平面图 ≈ 城市规划图」等类比讲解）；第二部分面向半导体从业者拓展视野

## 适用人群

- 微电子、集成电路入门本科生
- 跨行业转入半导体行业的从业者
- 芯片产业方向的科普学习者

## 前置基础

无需深厚电路基础。
